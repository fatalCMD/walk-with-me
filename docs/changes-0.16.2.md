# 0.16.2

Changes since 0.16:

- Experimental hand holding in Travel, off by default. Select one companion.
- Configurable lead-in and grip distances. Walking and non-sprint running supported.
- Hand-holding revision 11.2 fixes a scene refresh that cleared follower velocity.
  Wrist twisting and awkward approach/turning remain. Later pose experiments were rolled back.
- Optional glance toward followers during command gestures. Existing head targets take priority.
- Small fading icons for automatic rest and return to travel.
- Original third-person Lead, Companion and Rear gestures, with female variants.
  First-person clips still come from the separately installed FPI mod.
- Source files and docs use simpler names. Build and package references updated.
- GPL notices, dependency notices and the complete source archive included.

Replace the old package with Skyrim closed. Keep your INI to retain settings.
Wayfarer plugin, script, save and API names stay the same.

Native tests cover logic; animation appearance and other runtimes still need in-game checks.
