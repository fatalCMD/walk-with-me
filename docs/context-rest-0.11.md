# Rest 0.11

Relax stays anchored until another order. Automatic rest ends when the player leaves
its return range. Distant catch-up blends toward twice the selected cap using player
and destination distance. Full boost defaults to 1800/800 units; it ends by 500/200.
A near-player guard clears stale speed leases. Gait selection still owns Walk/Jog/Run;
SpeedMult and animation playback rates are untouched. Conversation selection considers
nearby clusters and prefers the largest available one.
