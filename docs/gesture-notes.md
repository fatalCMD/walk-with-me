# Early gesture notes

Historical FPI-based setup. Natural/Companion/Relax used wave, Lead used a left-hand
reach and Rear an open-palm clip. Only the animation channel was borrowed; no object
was activated. Missing assets fell back to wave. Cleanup released only the selector
owned by this mod, including after load.

Later releases bundle original third-person clips. Use usage.md for current
requirements. First-person FPI clips remain a separate dependency.
