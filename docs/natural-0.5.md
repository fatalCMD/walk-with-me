# Natural travel 0.5

Removed manual position editing, saved layout steering and the 0.4.2 crowd allocator.
Natural, Lead, Companion and Rear became broad preferences with stable per-follower
variation. Kept the 0.2.1 Travel template and connected-ground routing.
Walking can extend the route up to 140 units outdoors. This extension is excluded
from catch-up distance and freezes when the player stops. Useful straight routes
are retained; acquisition, turns and gait changes can still refresh them.
