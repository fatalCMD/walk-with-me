# Party life 0.14

Dialogue clearance defaults to 150 units, adjustable from 80 to 300. One unoccupied
managed companion at a time may move aside. The speaking NPC is never redirected.
Requests need connected navigation and prepared marker aliases; failed walks stop
after 15 seconds. No aliases are rebound during dialogue.
Personality uses the source plugin and local base NPC ID so load-order changes do
not reroll it. Ordinary controller and Papyrus dialogue guards remain active.
