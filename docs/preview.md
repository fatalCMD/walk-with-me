# Compatibility preview

Uses the same runtime selection as the SE/AE release. See docs/release.md in the
source for supported versions and dependencies. The 1.6/GOG and 1.7 paths are
not yet verified in game.

Close Skyrim, replace the old package and keep your INI if wanted. Enable
`Wayfarer.esp`. Check `Walk With Me.log` for runtime, hook and menu startup errors.
Test travel, the wheel, rest, dialogue and save/load. See docs/testing.md in the source.

The DLL links CommonLibSSE-NG 7.5.1 under GPL-3.0-or-later with the included
exceptions. Publish the matching Compatibility-Source.zip with this preview.
See LICENSING.md and docs/build.md.
