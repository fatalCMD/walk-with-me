# Relax 0.7

Renamed Sandbox to Relax in the UI; API mode 4 and legacy hotkey IDs stayed compatible.
Each follower rests around a fixed marker at their stopping point. Walking away does
not move it or add catch-up speed. Another order, disable or exclusion releases it.
Temporary rest keeps its return range. The order menu uses Cinzel Decorative under
its included OFL license; the framework's global font is unchanged.
