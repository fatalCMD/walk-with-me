# Sandbox 0.6

Added dedicated native Sandbox packages around follower marker aliases. Allowed
wandering, meals, conversation, idle markers and ordinary furniture. Skyrim chooses
reachable activities. The initial design used repeated radius growth; later versions
replaced it with one gate. Distant catch-up used 900/500-unit thresholds and twice
the selected multiplier. These are historical settings; see usage.md for current behavior.
