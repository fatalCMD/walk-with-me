# Spacing 0.13

Refresh a reused route when its lateral target moves by at least max(35 units,
half the goal threshold). Small jitter keeps the route. Spacing ranges from 0.6 to
3.0, with 0.2 button steps and default 0.88. Navigation can still narrow it.
Natural adds a straggler distance from 0 to 800, default 250. Parties below three
keep their layout; larger groups select one or two rear roles. Zero disables this.
