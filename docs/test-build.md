# Test build

Install through your mod manager with Skyrim closed. Replace the old copy and
keep your INI if needed. Use a separate save. Do not mix the DLL and scripts from
different builds.

Use the testing guide in the source. Test travel, orders, rest, dialogue and
save/load before optional gestures or hand holding. Report your runtime, mod list,
steps and `Walk With Me.log`. Animation reports need video.

Restore the previous complete package to roll back.
